## D. 품질 · 다듬기 (리뷰에서 나온 작은 지적)

- 화면
  - 접근성: 핀 버튼 `aria-pressed`, 완료 목록 토글 `aria-expanded`, 진행 바 `role="progressbar"`
  - 사라지는 항목의 높이를 접어서 목록이 덜컹거리지 않게 하기
  - 같은 내용의 알림이 연달아 뜨면 타이머가 다시 시작되도록 하기
  - 빠른 추가 처리 중에 새로 입력한 글자가 지워지지 않게 하기
  - 시작할 때 라벤더 테마가 잠깐 보이는 현상(다른 테마 사용 시), 핀 아이콘 깜빡임
  - 관리 창 상태를 불러오지 못하면 다시 시도 버튼 표시
  - 기록 탭의 기본 날짜를 달력 날짜가 아닌 업무일로 맞추기, "기록 없음" 범례 추가
  - 드래그 위치 표시, 키보드로 순서 바꾸기
- 백엔드
  - `get_today`가 바뀐 것이 없을 때는 DB에 쓰지 않도록 하기 (호출할 때마다 fsync 발생)
  - 과거 기록의 `repeat_type`, `due_time`, 바로가기 여부도 스냅샷으로 저장하기
  - 백업 불러오기 검증 강화: 바로가기 허용 형식, 이름 길이, 빈 요일 비트
  - 오류 문구에 섞인 영어 라이브러리 메시지를 로그로 빼고 한국어 문장만 표시
  - 자동 시작 등록 실패를 사용자에게 알리기
  - 위치 저장 디바운스를 스레드 하나로 처리하기
- 테스트
  - SettingsTab, Setup, WidgetApp 화면 테스트
  - 토스트 타이머, 주말 문구, 실패한 빠른 추가·되돌리기
  - 하루 시작 시각 변경, 템플릿 적용, 손상 DB 복구에 백업이 없는 경우
